# 猫哥素材工作台（仅源代码）

产品与素材索引界面，支持搜索、卡片/列表/表格、素材时间点、商品链接管理、批量编辑与回收站。

本仓库不包含真实商品图片、推广链接、素材索引、审核记录、原录像或云服务凭据。catalog-data.js 仅含空结构，主题 SVG 为界面装饰。

## 使用

- 静态预览：打开 index.html，显示空目录。
- 本地完整功能：Python 3.9+，设置 FOOTAGE_ROOT 为自己授权的素材目录，再运行 `python3 工作台服务.py 8787`。
- 数据仅写入运行目录的「数据」文件夹，默认忽略；服务只监听 127.0.0.1。
- 素材扫描仅按文件名登记日期，不自动判断产品，需要手工确认和补充。私人分析导入逻辑未包含。
- 静态托管只提供查询，原录像预览、保存修改、更新索引需要本地服务。

## 部署

将 HTML、JS、CSS 和主题 SVG 上传静态托管。业务数据独立管理，禁止将线上 catalog-data.js、商品图或本地数据反向提交到此仓库。
